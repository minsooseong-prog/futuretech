# 졸라맨 놀이터 (Stickman Playground)

마우스 커서로 **193가지** 상호작용을 할 수 있고, 아무것도 하지 않아도 **혼자 화면을 걸어 다니며 살아가는** 졸라맨 웹사이트입니다.

- 사람과 같은 관절 계층(척추·목·어깨·팔꿈치·손목·골반·무릎·발목)을 가진 16뼈 2D 스켈레톤
- 모든 관절이 **임계 감쇠 스프링**으로 수렴 → 뻣뻣하지 않고 살아 있는 느낌
- 잡아서 들면 **래그돌 물리**로 전환 → 흔들기·던지기·낙하 → 스스로 일어남
- 반응할 때 **말과 어울리는 몸동작을 반드시 함께** 재생 (84종 모션 클립)
- 말풍선 없이 **캐릭터 색상의 작은 텍스트**가 머리 위에 떠오르는 방식
- 열려 있는 창의 윗면은 **발판**이 되어 그 위로 점프해 올라감
- 배경 이미지 업로드 · 캐릭터 색상 변경 · 언어 설정(한/영/일)
- **빌드 도구·의존성 없음.** 그대로 GitHub에 올려 Vercel에 연결하면 끝

## 3. Vercel 연결

1. [vercel.com](https://vercel.com) 로그인 → **Add New… → Project**
2. 방금 만든 GitHub 저장소 **Import**
3. 설정에서 이것만 확인하세요:
   - **Framework Preset**: `Other`
   - **Build Command**: 비워 두기 (또는 `Override` 끄기)
   - **Output Directory**: 비워 두기 (루트 그대로 배포)
   - **Install Command**: 비워 두기
4. **Deploy** → 끝. `https://<프로젝트명>.vercel.app` 으로 열립니다.

이후 `git push` 할 때마다 자동으로 다시 배포됩니다.

### 로컬에서 먼저 보고 싶다면

ES 모듈은 `file://` 로 열면 CORS 때문에 막히므로 간단한 서버가 필요합니다.

```bash
npx serve .
#  또는
python3 -m http.server 5173
```

## 4. 조작법

| 입력 | 동작 |
|---|---|
| 졸라맨 클릭 | 부위별로 다른 반응 (머리·가슴·배·어깨·팔꿈치·손·무릎·발) |
| 더블클릭 | 부위별 특수 반응 |
| 잡고 끌기 | 래그돌 전환 → 흔들기 / 던지기 / 매달기 |
| 빈 곳에서 드래그 | **선택 박스** → 가두기·거대 박스·빈 박스 등 반응 + 명령 미니메뉴 |
| **우클릭** | 검색되는 명령 메뉴 (80여 개 동작) |
| 커서 제스처 | 흔들기 · 원 그리기 · 초고속 · 살금살금 · 호버 · 스치기 · 지그재그 |
| 휠 | 어지러워함 |
| ← → | 걷기 (Shift 함께 = 달리기) |
| Space | 점프 · **D** 춤 · **S** 앉기 · **Z** 자기 · **W** 인사 |
| **F** | 백덤블링 · **X** 발차기 · **C** 색 바꾸기 · **Q** 무작위 동작 |
| **H** | 메인 메뉴 · **Esc** 모든 창 닫기 |

찾아낸 상호작용은 **도감(★)** 에 하나씩 켜집니다.

## 5. 설정에서 할 수 있는 것

- **언어**: 한국어 / English / 日本語 (UI와 캐릭터 대사 모두 전환)
- **캐릭터 색상**: 10색 프리셋 · 컬러 피커 · 무지개 모드 · 랜덤
- **배경**: 내 이미지 업로드 (꽉 채우기 / 전체 보기 / 타일), 어둡게 조절, 지우기
- **크기 · 속도 · 글자 크기 · 바닥 높이**
- **자율 행동 / 물리 / 말하기 / 잔상** 켜고 끄기
- 전체 초기화

배경 이미지는 IndexedDB, 나머지 설정·게시판·도감은 localStorage에 저장되므로
**브라우저를 닫았다 열어도 그대로 유지**됩니다. (서버 없음 = 기기별 저장)

## 7. 직접 고쳐 보기

### 동작 추가하기 — `js/clips.js`

```js
add(C('내동작', 1.4, false, {
  armL_u: [[0, 0], [0.3, -150], [1, 0]],   // [시간(0~1), 각도(도)]
  head:   [[0, 0], [0.5, -12], [1, 0]],
}));
```

각도 규칙: **무릎 굽힘 +, 팔꿈치 굽힘 −, 팔 들어올림 −, 다리 앞으로 −, 상체 앞으로 숙임 +**

### 대사 추가하기 — `js/i18n.js`

```js
const SAY = {
  내키: [['한국어 대사'], ['English line'], ['日本語のセリフ']],
};
```

### 상호작용 연결하기 — `js/interactions.js`

```js
M('내명령', '내 동작', 'My move', '내동작', '내키');
```

`M(...)` 로 등록하면 우클릭 메뉴와 도감에 자동으로 나타나고, 총 개수도 자동으로 늘어납니다.

### 언어 추가하기 — `js/i18n.js`

`LANGS` 배열에 코드를 넣고, `UI` 와 `SAY` 각 항목의 배열에 **같은 순서로** 항목을 추가하면 됩니다.
빠뜨린 항목은 자동으로 첫 번째(한국어)로 대체됩니다.

## 8. 게시판을 진짜 공용으로 만들고 싶다면

지금 게시판은 브라우저 localStorage에만 저장됩니다(방문자끼리 공유되지 않음).
공용으로 바꾸려면 Vercel 프로젝트에 **Vercel KV** 를 붙이고 `api/posts.js` 를 만든 뒤,
`js/store.js` 의 `getPosts / addPost / removePost` 만 `fetch('/api/posts')` 로 갈아 끼우면 됩니다.
나머지 코드는 손댈 필요가 없습니다.
